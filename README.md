# Save Bite

## Төслийн танилцуулга

Save Bite нь ресторан, кофе шоп, нарийн боовны газар болон бусад хүнсний
байгууллагуудын борлогдож амжаагүй эсвэл хугацаа дуусах дөхсөн
хүнсний бүтээгдэхүүнийг хэрэглэгчдэд хямдралтай үнээр санал болгох систем юм.

## User Story

Save Bite системд нийт 12 User Story тодорхойлж,
GitHub Projects дээр Product Backlog үүсгэсэн.

User Story-уудыг дараах хэлбэрээр тодорхойлсон:

**Хэрэглэгчийн төрөл + юу хийхийг хүсэж байна + яагаад хийхийг хүсэж байна.**

## INVEST шалгалт

User Story-уудыг INVEST зарчмын дагуу шалгав.

- **Independent (Бие даасан):** User Story бүр тодорхой нэг үйлдлийг илэрхийлж, бусад story-оос аль болох бие даасан байна.
- **Negotiable (Хэлэлцэгдэх боломжтой):** Story-ийн хэрэгжүүлэх арга болон дэлгэрэнгүй шаардлагыг багийн гишүүд хэлэлцэн өөрчлөх боломжтой.
- **Valuable (Үнэ цэнтэй):** Story бүр хэрэглэгч эсвэл нийлүүлэгчид тодорхой үнэ цэнэ бий болгоно.
- **Estimable (Үнэлэгдэх боломжтой):** Story бүрийн хийх ажлын хэмжээг баг үнэлэх боломжтой.
- **Small (Жижиг):** Том функцуудыг бүртгүүлэх, нэвтрэх, хайх, захиалах, төлбөр төлөх зэрэг жижиг User Story болгон задалсан.
- **Testable (Туршигдах боломжтой):** Story бүрийг хэрэгжсэний дараа тухайн үйлдэл зөв ажиллаж байгаа эсэхийг туршиж шалгах боломжтой.
